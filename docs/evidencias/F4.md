## 2. Modelo y snapshot

```text
EstadoAtleta
  fecha, version_conocimiento, version_hash, generado_en, estado_id, hash
  secciones[]  -> Metrica[]
                   clave, etiqueta, valor, unidad, n, dispersion,
                   confianza, fuente[], limitaciones[], estado, detalle
```

- `estado_atleta` guarda `id`, `fecha`, `version_hash`, `json` y `creado_en`.
- El id no depende de la hora de generación. Dos cálculos seguidos con los mismos datos dan el mismo
  `estado_id`; cambiar la fecha o el contenido lo cambia.
- El snapshot actual de la base real es **`EA-e7cb90859f3a45c5`** (`2026-10-20`,
  `KV-baec56b27e293889`, 43 métricas, 5 `sin_datos`).
- `version_hash` guarda el hash completo del conocimiento (`baec56b27e293889ec9cf8e44bf78c648389991021e754bef36f3b2c2c1e6b9c`).
